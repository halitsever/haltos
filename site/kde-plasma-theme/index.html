A monochrome KDE Plasma 6 theme you can install without root

HaltOS started as the look of a Claude Code server reached over RDP. The theme part works on any KDE Plasma 6 desktop: one command themes your account without root, and one command puts your old setup back. Everything below is from the repository and its own screenshots.

Install it on your Plasma 6 desktop

git clone https://github.com/halitsever/haltos ~/haltos
~/haltos/install.sh user

Then log out and back in once, so running apps pick up the widget style. That is the whole install for your account. It needs Plasma 6; on Ubuntu that means 25.04 or newer.

install.sh user installs no packages. For the complete look, have these installed (Ubuntu package names):

sudo apt install qt6-style-kvantum fonts-jetbrains-mono fastfetch

Kvantum draws the widgets, JetBrains Mono is the font everywhere, and fastfetch prints the banner in new terminals. Without them the theme still applies, with Plasma's defaults in their place.

Optional, with root, for the parts outside your account:

sudo ~/haltos/install.sh system

That adds the SDDM login theme, the SSH login banner, the OS name in About this System and fastfetch, and makes HaltOS the default for accounts created later. Skip it on a machine you share.

Undo

The first install.sh user saves your KDE config to ~/.haltos-backup/kde-config-original.tar.gz and never overwrites that file. To restore it:

~/haltos/install.sh undo-user
sudo ~/haltos/install.sh undo-system   # only if you ran the system install

undo-user unpacks the saved config, removes the HaltOS colour scheme, Konsole files, wallpaper, Plasma and Kvantum themes, the VS Code theme and the prompt line in ~/.bashrc, then asks you to log out. undo-system restores Ubuntu's identity files, login banner and defaults.

Known limits

From the README:

  • The SDDM theme shows only when SDDM is the active display manager. Ubuntu flavours often ship GDM, and RDP sessions skip the login screen entirely.
  • Kvantum has no keyboard-only focus, so the focus frame is off to avoid boxes on every click. Inputs still show a ring when focused.
  • Chromium-based browsers keep their own theme unless Use GTK is selected in their appearance settings.
  • The Plymouth boot splash in the repository is not installed on Ubuntu today, because the installer looks for a tool Ubuntu does not ship. Plymouth themes shows how to set it by hand.

The whole HaltOS

On a fresh Ubuntu 25.04 or newer server, one command installs claude-code-vps (Plasma over RDP, hardened SSH, Docker, Claude Code) and this theme on top. The HaltOS home page covers that setup, and xrdp looks different from your desktop? explains how the theme reaches an RDP session.

Questions

Does the HaltOS theme work on Kubuntu, Fedora KDE or Arch?

The user install needs Plasma 6 and the kwriteconfig6, qdbus6, plasma-apply-colorscheme and plasma-apply-wallpaperimage commands, which Plasma 6 ships. It is tested on Ubuntu 25.04 and newer. On other distributions the user part should apply, but only Ubuntu is tested.

Do I need root to install it?

No. install.sh user writes only into your home folder. Root is only needed for install.sh system, which adds the login screen, MOTD, OS identity and defaults for new accounts.

How do I go back to my old theme?

Run install.sh undo-user. It restores the KDE config saved in ~/.haltos-backup/kde-config-original.tar.gz before the first install and removes the HaltOS files from your home folder.

Does the user install affect other accounts?

No. install.sh user changes only the account that runs it. Other users keep their own theme unless you also run install.sh system, which sets defaults for accounts created afterwards.

root@haltos:~# shutdown -h never
