What the command does

      
Run it as root on a fresh Ubuntu 25.04 or newer server. Options after bash -s -- go to claude-code-vps, for example --user dev --yes.

    

    
    
      
  1. 
        
    Checks for Plasma 6
    
        
    Before installing anything. On Ubuntu 24.04, which ships Plasma 5, it stops and says why.
    
      
    2. 
      
  2. 
        
    Sets up the workstation
    
        
    claude-code-vps adds your sudo user, key-only SSH, ufw, Plasma over RDP on port 53389, Docker and Claude Code.
    
      
    3. 
      
  3. 
        
    Gives the system its name
    
        
    HaltOS identity files, login banner, Kvantum, the SDDM and Plymouth themes, and defaults for new users.
    
      
    4. 
      
  4. 
        
    Dresses your desktop
    
        
    Your user gets the theme right away. The panel and wallpaper finish on your first RDP login.
    
      
    5. 
    

    

      
# update both layers later

      
sudo claude-vps update && sudo haltos update

      
# put Ubuntu back the way it was

      
~/haltos/install.sh undo-user && sudo ~/haltos/install.sh undo-system

    

  


  

    

      
Why the name

    

    

      
HALTOS(7)HaltOS ManualHALTOS(7)

      
NAME

      
haltos - an operating system named after the command that stops one

      
DESCRIPTION

      
halt is the oldest way to stop a Unix machine. HaltOS takes the word and turns it around: a desktop that lives on a server that never sleeps, so Claude Code keeps working while you are away. Its wallpaper says it plainly: shutdown -h never.

      
Take the i out of Halit, the name of the person who made it, and you get halt.

      
CODENAME

      
SIGKILL, the one signal a process cannot catch or ignore. The first release is the one that ends the half-measures.

      
SEE ALSO

      
halt(8), shutdown(8), signal(7), claude-code-vps

    

  


  

    

      
Questions

    

    

      Is HaltOS a Linux distribution?
      
No. It is a layer on top of Ubuntu. Packages and updates still come from Ubuntu, and /etc/os-release keeps ID=ubuntu so apt, PPAs and vendor install scripts keep working. HaltOS changes how the system looks and introduces itself.

    

    

      Which Ubuntu releases does it support?
      
Ubuntu 25.04 or newer, because HaltOS needs KDE Plasma 6. Ubuntu 24.04 ships Plasma 5, and the installer stops before changing anything there.

    

    

      Do I need claude-code-vps?
      
The one-command install includes it. claude-code-vps sets up the server and keeps your config in sync from a git repository, HaltOS owns the look. claude-code-vps also works on its own, and HaltOS keeps its theme files out of your synced dotfiles.

    

    

      Will a claude-vps sync undo the theme?
      
No. HaltOS lists the files it owns in claude-vps's local-only list, so a sync leaves them alone and a publish never pushes them into your public dotfiles.

    

    

      How do I remove it?
      
~/haltos/install.sh undo-user restores the KDE config saved before the first install. sudo ~/haltos/install.sh undo-system restores Ubuntu's identity files, login banner and defaults.
