Installing and switching SDDM login screen themes

SDDM is the login screen KDE Plasma uses. Its look comes from a theme: a folder of QML and images that the greeter loads. This post covers where themes live, how to switch them with or without a desktop, how to test one safely, and the catch for remote desktops, using the HaltOS theme as the example.

Where themes live

ls /usr/share/sddm/themes/

Each folder is one theme. A Qt 6 theme for current SDDM needs at least:

FilePurpose
metadata.desktopName, author, main QML file, config file, Qt version
Main.qmlThe login screen itself, written in QML
theme.confSettings the QML reads, such as the background image
imagesBackgrounds, logos

The HaltOS theme's metadata.desktop:

[SddmGreeterTheme]
Name=HaltOS
Description=HaltOS monochrome login
Type=sddm-theme
MainScript=Main.qml
ConfigFile=theme.conf
Theme-Id=haltos
Theme-API=2.0
QtVersion=6

QtVersion=6 tells SDDM to start its Qt 6 greeter (sddm-greeter-qt6). A theme written for Qt 5 without that line may fail to load on a Plasma 6 system.

Switch themes in System Settings

On Plasma 6: System Settings → Colors & Themes → Login Screen (SDDM). Pick a theme, apply, enter your password. The same page has buttons to get new themes from the KDE Store and to install one from a file, and it writes the choice into SDDM's config for you.

Switch themes from the terminal

The sddm.conf man page lists the load order: /usr/lib/sddm/sddm.conf.d, then /etc/sddm.conf.d, then /etc/sddm.conf, with the latter having the highest precedence. Files inside a folder are read in name order. HaltOS's install.sh writes its choice like this:

sudo install -d /etc/sddm.conf.d
printf '[Theme]\nCurrent=haltos\n' | sudo tee /etc/sddm.conf.d/90-haltos.conf

The 90- prefix matters. On one HaltOS machine, an Ubuntu Budgie package had already installed 50-ubuntu-budgie.conf with Current=ubuntu-budgie-login. Because 90-haltos.conf sorts later, its Current=haltos wins. Check what a machine has with:

grep -r Current /etc/sddm.conf /etc/sddm.conf.d/ 2>/dev/null

A Current= line in /etc/sddm.conf itself would still beat every drop-in, so check that file too. The change applies the next time the greeter starts: after a log out or reboot.

Test a theme without logging out

sddm-greeter-qt6 --test-mode --theme /usr/share/sddm/themes/haltos

That opens the login screen in a window on your current desktop. You cannot log in from it, but you can see the layout and catch QML errors in the terminal output before you make the theme the default and lock yourself out of a working login screen.

Install a theme by hand

sudo cp -r my-theme /usr/share/sddm/themes/
sddm-greeter-qt6 --test-mode --theme /usr/share/sddm/themes/my-theme
printf '[Theme]\nCurrent=my-theme\n' | sudo tee /etc/sddm.conf.d/90-theme.conf

Themes from the KDE Store come as archives; unpack them so the folder with metadata.desktop sits directly under themes/.

When the theme never shows

Two cases from the HaltOS README:

  • SDDM is not the display manager. Many Ubuntu flavours use GDM. The theme files can be installed, and /etc/sddm.conf.d/ can point at them, but nobody sees them. HaltOS installs the theme only when /usr/share/sddm/themes exists, and says it is used when SDDM is the active display manager.
  • You connect over RDP. xrdp shows its own login dialog and starts your desktop session directly, without SDDM. On a server set up with claude-code-vps, SDDM is even disabled, because nobody logs in at the console. The HaltOS login theme then only appears if you attach a display. xrdp looks different from your desktop? covers what xrdp does start.

Undo

HaltOS removes its theme with sudo haltos undo-system, which deletes /usr/share/sddm/themes/haltos and /etc/sddm.conf.d/90-haltos.conf. By hand, delete your drop-in file and the previous theme comes back. The boot splash before SDDM is a separate system; see Plymouth themes.

Questions

Where are SDDM themes stored?

System-wide themes live in /usr/share/sddm/themes, one folder per theme. The folder name is the theme name SDDM uses in its config.

How do I change the SDDM theme from the terminal?

Create a file in /etc/sddm.conf.d/ with [Theme] on one line and Current=<theme folder name> on the next. Files there are read in name order and later ones win, so give yours a high number.

Why does my SDDM theme not show over RDP?

RDP sessions through xrdp log in with xrdp's own login dialog and never start SDDM, so the theme is only seen on a local display.
