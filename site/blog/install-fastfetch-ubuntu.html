How to install fastfetch on any current Ubuntu release

fastfetch prints your system information next to a distribution logo, the job neofetch used to do. Whether apt can install it depends on your Ubuntu release. This post lists the route for each one, checked against Launchpad and the fastfetch README on 28 November 2026, and shows how HaltOS installs and starts it.

Which route for which release

UbuntuInstall with
25.04 and newersudo apt install fastfetch
24.04 LTS (noble)the fastfetch PPA, or the .deb from GitHub releases
22.04 LTS (jammy)the fastfetch PPA, or the .deb
20.04the .deb

The fastfetch README gives these routes: apt on "Debian 13 or newer; Ubuntu 25.04 or newer", the PPA ppa:zhangsongcui3371/fastfetch for "Ubuntu 22.04 or newer; latest version", and a .deb from the release page for Ubuntu 20.04 and later. Launchpad agrees: on the date above it listed no official noble package. It listed 2.57.1 for resolute (26.04), 2.66.0 for stonking and 2.70.0 for the release in development.

Ubuntu 25.04 and newer: apt

sudo apt update
sudo apt install fastfetch
fastfetch --version

On a HaltOS machine running Ubuntu 26.04 this prints fastfetch 2.57.1 (x86_64). The archive version trails the upstream release, which is fine for most people. For the newest version, use the PPA below on these releases too.

Ubuntu 24.04 and 22.04: the PPA

sudo add-apt-repository ppa:zhangsongcui3371/fastfetch
sudo apt update
sudo apt install fastfetch

The PPA is run by a fastfetch maintainer and the README recommends it for the latest version. Packages from a PPA update with the rest of the system through apt upgrade.

Any release: the .deb

Download fastfetch-linux-amd64.deb (or the arm64 one) from the releases page, then:

sudo apt install ./fastfetch-linux-amd64.deb

Using apt install with a path, rather than dpkg -i, pulls in any missing dependencies. A .deb does not update itself; download the new one when you want an upgrade.

Run it

fastfetch

That prints the logo of your distribution and a list of modules: OS, kernel, uptime, packages, shell, desktop, CPU, memory, disk and more. Useful flags from fastfetch --help:

FlagDoes
--list-logosList the built-in logos
-l <name>Use a different logo, or none
--list-modulesList every module it can show
-c <preset>Load a config or preset, for example -c neofetch or -c all
--gen-configWrite a starter config file

How HaltOS installs it

HaltOS needs Plasma 6, so it only runs on Ubuntu 25.04 and newer, where apt has the package. The system step of install.sh installs it with the other packages it needs:

apt-get install -y -qq fastfetch qt6-style-kvantum python3-pyside6.qtwidgets libglib2.0-bin

It then puts its config in /etc/xdg/fastfetch/config.jsonc for every user, and a per-user copy in ~/.config/fastfetch/config.jsonc that points at the HALTOS banner. The fastfetch config post walks through that file.

Show it when a terminal opens

HaltOS starts fastfetch from its bash prompt script, once per terminal:

if [ -z "$HALTOS_GREETED" ] && [ -z "$TMUX" ] && command -v fastfetch >/dev/null; then
    export HALTOS_GREETED=1
    fastfetch
fi

Three guards worth copying: command -v skips it where fastfetch is not installed, $TMUX keeps every tmux pane from printing it again, and the exported HALTOS_GREETED keeps nested shells quiet. Add the same block to the end of ~/.bashrc or ~/.zshrc.

For SSH logins, the login banner is a better place for system figures than the shell. What is MOTD covers how HaltOS does that.

Remove it

sudo apt remove fastfetch
rm -rf ~/.config/fastfetch

If you used the PPA, also remove it with sudo add-apt-repository --remove ppa:zhangsongcui3371/fastfetch. Coming from neofetch? fastfetch vs neofetch covers the switch.

Questions

Is fastfetch in the Ubuntu 24.04 repositories?

No. On 28 November 2026 Launchpad listed no official fastfetch package for noble. Use the PPA ppa:zhangsongcui3371/fastfetch or the .deb from the GitHub releases page.

Which Ubuntu versions have fastfetch in apt?

The fastfetch README says apt install fastfetch works on Ubuntu 25.04 or newer and Debian 13 or newer.

How do I run fastfetch every time I open a terminal?

Add a line that runs fastfetch to the end of ~/.bashrc or ~/.zshrc. Guard it with command -v fastfetch so a machine without it still starts cleanly.
