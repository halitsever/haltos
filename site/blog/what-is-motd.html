MOTD on Linux servers, and how to write your own

MOTD stands for message of the day: the text a server prints right after you log in over SSH. On Ubuntu it is built fresh at each login from a folder of small scripts, which is why it shows system load one minute and an Ubuntu Pro notice the next. This post explains how that works and how HaltOS replaces it with one script.

Static and dynamic MOTD

The classic MOTD is a text file, /etc/motd, printed after login. Edit it and every user sees the new text. It is static: it says the same thing until someone edits it again.

Ubuntu adds a dynamic part. At each login, PAM's pam_motd module runs every executable script in /etc/update-motd.d/ in name order, and prints what they output. That is where the "Welcome to Ubuntu" header, the system load table and the update counts come from.

What is in /etc/update-motd.d

On an Ubuntu 26.04 server with HaltOS installed, the folder holds:

00-haltos
00-header
10-help-text
50-landscape-sysinfo
50-motd-news
85-fwupd
90-updates-available
91-contract-ua-esm-status
91-release-upgrade
92-unattended-upgrades
95-hwe-eol
97-overlayroot
98-fsck-at-reboot
98-reboot-required

Each comes from a package: base-files for the header and help text, landscape-common for the system information, ubuntu-pro-client for the ESM status, update-notifier-common for update counts and reboot notices, and so on. Only files with the execute bit run.

To see what a login would print, run them yourself:

sudo run-parts /etc/update-motd.d/

Turning off the parts you do not want

Two ways, both safe across package upgrades:

Remove the execute bit. The file stays, so the package manager is happy, but it no longer runs:

sudo chmod -x /etc/update-motd.d/50-motd-news

Use the setting, where there is one. The news fetcher reads /etc/default/motd-news:

ENABLED=0

Deleting the scripts also works until the package that owns them is updated and puts them back.

For a single user who wants no banner at all, touch ~/.hushlogin quiets the login messages for that account.

How HaltOS replaces the banner

The HaltOS install.sh does two things. It installs its own script as 00-haltos, and it turns six of Ubuntu's scripts off with chmod -x:

MOTD_OFF="00-header 10-help-text 50-motd-news 50-landscape-sysinfo 90-updates-available 91-contract-ua-esm-status"

The others stay on, so reboot-required, release-upgrade and similar notices still appear when they apply. sudo haltos undo-system sets the execute bit back on all six and removes 00-haltos.

The HaltOS MOTD script, in parts

The full script is system/motd/00-haltos. It is POSIX sh, not bash, and CI checks it with shellcheck in sh mode. What it reads:

LineFrom
Name and versionPRETTY_NAME, VERSION_ID in /etc/os-release
Kerneluname -r
Uptimeuptime -p
Loadfirst three fields of /proc/loadavg
Memoryfree -h, used / total
Diskdf -h /, used / total and percent
Addressfirst address from hostname -I
Updatesapt's own count from /var/lib/update-notifier/updates-available

Two details worth copying:

  • Update counts without the upsell. Instead of running Ubuntu's 90-updates-available, which also prints Ubuntu Pro advertising, it reads the file update-notifier already writes and pulls the two numbers out with sed, printing N pending (M security) or up to date.
  • Release notices. A systemd timer checks GitHub once a day for a newer HaltOS release and stores it in /var/lib/haltos/latest. The MOTD compares that with the installed version and adds a line with the update command when a newer one exists. The login stays fast, because the network check happened earlier.

The banner itself is an H drawn in box characters next to the figures, in the same three greys as the rest of the theme.

Write your own

A minimal script:

#!/bin/sh
. /etc/os-release
printf '\n  %s\n' "$PRETTY_NAME"
printf '  load   %s\n' "$(cut -d' ' -f1-3 /proc/loadavg)"
printf '  disk   %s\n\n' "$(df -h / | awk 'NR==2 {print $3 " / " $2}')"

Save it as /etc/update-motd.d/01-custom, sudo chmod +x it, and log in again over SSH. Keep it fast: every second it spends is a second added to every login. Anything that needs the network belongs in a timer, as above, not in the MOTD script.

MOTD in games

Search for MOTD and you will also find Minecraft and other game servers. There it means the short message shown in the server list. Same name, unrelated feature.

Questions

What does MOTD mean?

Message of the day. On Linux it is the text shown after a login, traditionally the contents of /etc/motd. Game servers such as Minecraft use the same name for the line shown in the server list, which is unrelated.

Where is the MOTD on Ubuntu?

Ubuntu builds it at login from the executable scripts in /etc/update-motd.d, run in name order. The static /etc/motd file is shown too if it exists.

How do I disable the Ubuntu MOTD news?

Set ENABLED=0 in /etc/default/motd-news, or remove the execute bit from /etc/update-motd.d/50-motd-news with chmod -x.
