Changing the Plymouth boot splash on Ubuntu and Debian

Plymouth draws the graphics between the boot loader and the login screen. Changing its theme is a two-part job on most systems: pick the theme, then rebuild the initramfs so the theme is there early in boot. Ubuntu does this differently from Debian, and many servers never show a splash at all. This post covers all three, and an honest note on the HaltOS splash.

What a theme is

Themes live in /usr/share/plymouth/themes/, one folder each. The folder holds a .plymouth file plus images or a script. HaltOS's haltos.plymouth:

[Plymouth Theme]
Name=HaltOS
Description=HaltOS ASCII boot splash
ModuleName=script

[script]
ImageDir=/usr/share/plymouth/themes/haltos
ScriptFile=/usr/share/plymouth/themes/haltos/haltos.script

ModuleName=script means the theme is a small program in Plymouth's script language that draws images (here a wordmark, a progress track and bar, and a cursor) frame by frame. Other plugins such as two-step and text are configured with settings instead of a script.

List what is installed:

ls /usr/share/plymouth/themes/

Change the theme on Ubuntu

Ubuntu chooses the theme through the alternatives system, with the link name default.plymouth. On an Ubuntu 26.04 machine:

$ update-alternatives --display default.plymouth
default.plymouth - auto mode
  link best version is /usr/share/plymouth/themes/bgrt/bgrt.plymouth
  link currently points to /usr/share/plymouth/themes/bgrt/bgrt.plymouth

To switch to a theme you installed into /usr/share/plymouth/themes/mytheme/:

sudo update-alternatives --install /usr/share/plymouth/themes/default.plymouth \
  default.plymouth /usr/share/plymouth/themes/mytheme/mytheme.plymouth 100
sudo update-alternatives --config default.plymouth
sudo update-initramfs -u

The last line copies the theme into the initramfs. Without it, the old theme keeps showing, because Plymouth starts before the root filesystem is mounted.

Change the theme on Debian, Fedora and Arch

These ship a helper script:

plymouth-set-default-theme --list
sudo plymouth-set-default-theme -R mytheme

-R rebuilds the initramfs in the same step. Ubuntu does not ship this script: a search of Ubuntu's package contents for the file name finds nothing. Guides that tell Ubuntu users to run it are written for another distribution.

The splash flag

Plymouth only draws graphics when the kernel command line contains splash. Check yours:

cat /proc/cmdline

Desktop installs usually have quiet splash. Cloud and VPS images often do not, and many send the console to a serial port instead, so nothing graphical ever appears. To turn it on with GRUB, edit GRUB_CMDLINE_LINUX_DEFAULT in /etc/default/grub to include splash, then sudo update-grub and reboot. On a VPS you will only see it in the provider's graphical console, if it has one.

Preview without rebooting

sudo plymouthd
sudo plymouth --show-splash
sleep 5
sudo plymouth quit

Run it from a text console (Ctrl+Alt+F3), not from inside a graphical session, or the splash and your desktop fight over the screen.

A note on the HaltOS splash

HaltOS ships the theme above and its README lists "a Plymouth splash with a blinking cursor". Its installer only installs the theme when plymouth-set-default-theme exists:

if command -v plymouth-set-default-theme >/dev/null; then

Because Ubuntu does not ship that script, on Ubuntu, the only system HaltOS supports, this step is skipped today and the HaltOS splash is not installed. The HaltOS README also notes that the splash needs splash on the kernel command line, which many cloud images lack. To use the theme now, copy plymouth/haltos/ from the repository into /usr/share/plymouth/themes/haltos/ and follow the Ubuntu steps above with haltos/haltos.plymouth.

The graphical splash that does appear on HaltOS after login is the Plasma splash (KSplash), which is a different system and part of the Plasma theme.

Undo

On Ubuntu, sudo update-alternatives --config default.plymouth back to the previous entry, then sudo update-initramfs -u. With the helper script, sudo plymouth-set-default-theme --reset and rebuild. The login screen after the splash is configured separately; see SDDM themes.

Questions

Where are Plymouth themes stored?

In /usr/share/plymouth/themes, one folder per theme, each with a .plymouth file that names the plugin and its files.

How do I change the Plymouth theme on Ubuntu?

Register the theme with update-alternatives for default.plymouth, select it with update-alternatives --config default.plymouth, then run sudo update-initramfs -u.

Why do I not see a boot splash on my server?

Plymouth only shows a splash when splash is on the kernel command line. Many cloud images boot without it, often with a serial console instead.
