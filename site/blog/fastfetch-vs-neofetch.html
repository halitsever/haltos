fastfetch or neofetch: the differences that matter now

For years neofetch was the default way to print a logo and your system details in a terminal screenshot. It is no longer maintained, and fastfetch has taken its place in most setups, including HaltOS. Here is what changed, using each project's own repository as the source, and how to move over without losing your layout.

Speed

The fastfetch FAQ says "Fastfetch is faster, as the name suggests". It does not quote numbers in the README; it links a benchmark. The reason is the implementation: neofetch is a shell script that starts many small programs to gather each value, and fastfetch is a compiled program that reads most values directly. If start-up time matters to you, measure on your own machine:

time fastfetch
time neofetch

Why it matters that neofetch is archived

An archived project gets no fixes. Detection for CPUs, desktops, package managers and distribution logos that appeared after 2020 will not be added, and bugs stay open. Distribution packages stay on 7.1.0. Nothing breaks overnight, but the output gets less accurate over time.

Switch in three steps

  1. Install fastfetch: install fastfetch on Ubuntu covers apt, the PPA and the .deb.
  2. Keep the neofetch look with the built-in preset:
fastfetch -c neofetch
  1. Make it permanent by copying the preset and editing it:
mkdir -p ~/.config/fastfetch
cp /usr/share/fastfetch/presets/neofetch.jsonc ~/.config/fastfetch/config.jsonc

Then replace neofetch with fastfetch wherever your shell starts it, for example at the end of ~/.bashrc or ~/.zshrc. Guard it so machines without it still start:

command -v fastfetch >/dev/null && fastfetch

Your old config.conf does not carry over. It is a bash script, and fastfetch reads JSONC. Rebuild the parts you changed (logo, colours, which lines are shown) using the fastfetch config guide.

What HaltOS uses

HaltOS uses fastfetch, installed from apt, with its own banner and a config that shows OS, kernel, uptime, packages, shell, desktop, CPU, memory, disk and network. The bash prompt script runs it once per terminal, skipping tmux panes and nested shells. The screenshot above is that output.

When neofetch is still fine

If you already have it, it still runs, and a screenshot of your desktop does not need new CPU detection. For a new setup, start with fastfetch. Removing neofetch is sudo apt remove neofetch on Ubuntu, plus rm -rf ~/.config/neofetch if you want its config gone too.

Questions

Is neofetch discontinued?

Its GitHub repository was archived by the owner on 26 April 2024 and is read-only. The last release is 7.1.0 from December 2020.

Is fastfetch faster than neofetch?

The fastfetch FAQ says it is faster, as the name suggests, and that it is written mainly in C. neofetch is a bash script. The README links a benchmark rather than quoting numbers.

Can fastfetch look like neofetch?

Yes. fastfetch ships a neofetch preset: run fastfetch -c neofetch, or copy the preset file into ~/.config/fastfetch/config.jsonc.
