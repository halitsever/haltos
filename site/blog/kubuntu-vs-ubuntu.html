What actually differs between Kubuntu and Ubuntu

Kubuntu and Ubuntu install the same packages from the same archive. What differs is the desktop that comes preinstalled, and the applications and settings around it. This post lays out the differences with package data from Ubuntu 24.04 and 26.04 containers, and explains why HaltOS starts from Ubuntu Server rather than either desktop image.

The short version

Ubuntu DesktopKubuntu
DesktopGNOMEKDE Plasma
Toolkit of the core appsGTKQt
Login screenGDMSDDM
Package archiveUbuntuUbuntu, the same one
Made byCanonicalUbuntu community members

Ubuntu's flavours page describes flavours as each having their own choice of default applications and settings, owned and developed by members of the community and backed by the full Ubuntu archive. For Kubuntu it says: Kubuntu unites Ubuntu with KDE and the Plasma desktop.

So a package you install on one installs the same way on the other. Kernel, apt, snaps and security updates come from the same place.

Support periods

Ubuntu's release cycle page says LTS releases receive five years of standard security maintenance, and that the release cycle for flavours may differ. It sends you to each flavour's own site for its support policy. Check Kubuntu's before you pick an LTS for a long-lived machine.

Plasma versions per release

Which Plasma you get depends on the release. From apt-cache policy plasma-workspace in official containers on 28 November 2026:

Releaseplasma-workspace
Ubuntu 24.04.5 LTS5.27.12 (Plasma 5)
Ubuntu 26.04.1 LTS6.6.7 (Plasma 6)

Those packages are the same whether you start from Kubuntu or from Ubuntu.

Kubuntu on top of Ubuntu

Because the archive is shared, you can turn an Ubuntu install into Kubuntu, or add Plasma beside GNOME. Two metapackages matter:

Packageapt descriptionDirect dependencies on 26.04
kubuntu-desktopKubuntu Plasma Desktop/Netbook system80 Depends, 166 Recommends
kde-plasma-desktopKDE Plasma Desktop and minimal set of applications7 Depends, 6 Recommends
sudo apt install kubuntu-desktop      # the whole Kubuntu set
sudo apt install kde-plasma-desktop   # Plasma with a few apps

Installing either next to GNOME adds a Plasma session you can pick at login, next to the GNOME one.

On a server

Neither desktop image fits a VPS that has no screen. claude-code-vps, which HaltOS builds on, starts from Ubuntu Server and installs the minimal metapackage plus what a remote desktop needs: kde-plasma-desktop, plasma-session-x11, kwin-x11, Konsole, Dolphin, Kate, fonts including fonts-jetbrains-mono, and breeze-gtk-theme. It then turns the login screen off and boots to the console, because nobody sits in front of a server. You reach the desktop over RDP, as the xrdp post explains.

HaltOS's bootstrap.sh checks the Plasma version first and stops with a message on releases without Plasma 6:

plasma=$(apt-cache policy plasma-workspace | awk '/Candidate:/ {sub(/^[0-9]+:/, "", $2); print $2}')
[ "${plasma%%.*}" -ge 6 ] 2>/dev/null || die "HaltOS needs Plasma 6, ..."

That is why HaltOS needs Ubuntu 25.04 or newer.

Which to choose

  • A laptop or desktop where you want Plasma: Kubuntu. It ships Plasma configured as a whole, with Discover, SDDM and its applications set up together.
  • You already run Ubuntu and want to try Plasma: install kde-plasma-desktop and pick the session at login.
  • A server: Ubuntu Server, with the minimal Plasma packages only if you need a remote desktop.
  • You like GNOME: Ubuntu as it comes.

Questions

Is Kubuntu the same as Ubuntu?

It is Ubuntu with a different default desktop. Ubuntu's flavours page says Kubuntu unites Ubuntu with KDE and the Plasma desktop, and that flavours are backed by the full Ubuntu archive for packages and updates.

Can I install KDE Plasma on Ubuntu instead of Kubuntu?

Yes. kubuntu-desktop installs the full Kubuntu set, and kde-plasma-desktop installs Plasma with a minimal set of applications. Both come from the normal Ubuntu archive.

Which Ubuntu release has Plasma 6?

In the containers checked on 28 November 2026, Ubuntu 24.04 offered plasma-workspace 5.27.12 and Ubuntu 26.04 offered 6.6.7. HaltOS requires Plasma 6 and stops on 24.04.
