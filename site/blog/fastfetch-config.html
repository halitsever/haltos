Writing a fastfetch config with your own logo and colours

fastfetch does not create a config file on its own. Without one you get the defaults: your distribution's logo and a long list of modules. With one, you choose the logo, the colours, the labels and which lines appear. This post goes through the config HaltOS ships, which replaces the logo with a generated HALTOS banner.

Where fastfetch looks

fastfetch --list-config-paths

On a HaltOS machine this prints, in order:

/home/halit/.config/fastfetch/ (*)
/home/halit/fastfetch/
/home/halit/.config/kdedefaults/fastfetch/
/etc/xdg/fastfetch/ (*)
/usr/share/desktop-base/kf5-settings/fastfetch/
/etc/fastfetch/

The asterisk marks folders that exist. A user file in ~/.config/fastfetch/config.jsonc takes precedence over the system one in /etc/xdg/fastfetch/. HaltOS writes both: the system file is the default for every account, and each user it themes gets a copy.

To start from scratch:

fastfetch --gen-config        # minimal
fastfetch --gen-config-full   # every option, commented

The file is JSONC: JSON that allows comments. The first line of HaltOS's file points at fastfetch's JSON schema, so an editor such as VS Code autocompletes every key.

The HaltOS config

From system/fastfetch/config.jsonc, the logo part:

"logo": {
  "type": "file",
  "source": "/usr/share/haltos/fastfetch/haltos.txt",
  "color": { "1": "38;2;250;250;250", "2": "38;2;113;113;122" },
  "padding": { "right": 3, "top": 1 }
}
  • type: file reads the logo from a text file instead of the built-in list.
  • color defines colour slots. Each value is an ANSI SGR sequence: 38;2;R;G;B is a 24-bit foreground colour. Slot 1 is near-white (250, 250, 250), slot 2 is the grey of the palette (113, 113, 122).
  • padding puts three columns between logo and text and one line above.

The logo file and its colour slots

The banner file is generated by tools/build-assets.py and looks like this:

$1██╗  ██╗ █████╗ ██╗  ████████╗ ██████╗ ███████╗
$1██║  ██║██╔══██╗██║  ╚══██╔══╝██╔═══██╗██╔════╝
$1███████║███████║██║     ██║   ██║   ██║███████╗
$1██╔══██║██╔══██║██║     ██║   ██║   ██║╚════██║
$1██║  ██║██║  ██║███████╗██║   ╚██████╔╝███████║
$1╚═╝  ╚═╝╚═╝  ╚═╝╚══════╝╚═╝    ╚═════╝ ╚══════╝
$2  v1.3 // SIGKILL

$1 and $2 switch to colour slots 1 and 2. The banner is white and the version tag underneath is grey. Generating it from a script means the version and codename update with each release instead of being edited by hand.

To use your own art, save it to a file, add $1 (and more slots if you want), and point logo.source at it. To try a file without editing the config: fastfetch -l /path/to/logo.txt. To pick a built-in logo instead: fastfetch --list-logos, then "logo": "arch" or any other name.

Display settings

"display": {
  "separator": "  ",
  "color": { "keys": "38;2;113;113;122", "title": "38;2;250;250;250", "output": "38;2;228;228;231" }
}

Two spaces between key and value instead of the default colon, grey keys, white title and light grey values. Three colours, all from the same zinc palette the Konsole theme uses.

Modules

"modules": [
  "title",
  { "type": "custom", "format": "\u001b[38;2;113;113;122m────────────────────────────" },
  { "type": "command", "key": "os    ", "text": ". /etc/os-release && echo \"$PRETTY_NAME $(uname -m)\"" },
  { "type": "kernel", "key": "kernel" },
  { "type": "uptime", "key": "uptime" },
  { "type": "packages", "key": "pkgs  " },
  { "type": "shell", "key": "shell " },
  { "type": "de", "key": "de    " },
  { "type": "cpu", "key": "cpu   " },
  { "type": "memory", "key": "mem   " },
  { "type": "disk", "key": "disk  ", "folders": "/" },
  { "type": "localip", "key": "net   ", "compact": true },
  "break",
  { "type": "colors", "symbol": "block" }
]

Things worth noting:

  • Keys are padded by hand to six characters, so values line up in a column without a separator character.
  • **custom** prints any text. Here it draws a grey rule under the title.
  • **command** runs a shell command and prints its output. HaltOS uses it for the OS line so it reads PRETTY_NAME from /etc/os-release (which HaltOS rebrands) plus the architecture.
  • **disk with folders: "/"** shows only the root filesystem instead of every mount.
  • **break is an empty line, and colors** prints the terminal's 16-colour palette as blocks.

fastfetch --list-modules lists all of them.

Presets

fastfetch ships example configs. List them with fastfetch --list-presets and try one with -c:

fastfetch -c neofetch      # neofetch-like layout
fastfetch -c all           # every module
fastfetch -c examples/8    # one of the numbered examples

Copy one from /usr/share/fastfetch/presets/ into ~/.config/fastfetch/config.jsonc and edit from there.

Get the HaltOS look without HaltOS

On any Plasma 6 machine, install.sh user from the HaltOS repository installs the banner and writes this config into your home folder, along with the rest of the theme. Or copy the two files above by hand: the config into ~/.config/fastfetch/, the banner anywhere, with logo.source pointing at it.

Questions

Where is the fastfetch config file?

The default user config is ~/.config/fastfetch/config.jsonc. fastfetch --list-config-paths prints every folder it searches, including /etc/xdg/fastfetch for system-wide configs.

How do I create a fastfetch config?

Run fastfetch --gen-config for a minimal file, or --gen-config-full for one with every option. Then edit ~/.config/fastfetch/config.jsonc.

How do I use my own ASCII art as the fastfetch logo?

Save the art in a text file, set logo.type to file and logo.source to its path. Put $1, $2 and so on in the file to switch between the colours set in logo.color.
